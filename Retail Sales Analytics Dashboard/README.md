# Superstore Sales Analytics Dashboard

## Project Overview
This project analyzes retail sales data using Excel, MySQL, and Power BI to uncover business insights related to sales performance, profitability, regional trends, and discount impact.

## Tools Used
- Excel
- MySQL
- Power BI
- SQL

## Key Features
- KPI Cards for Sales, Profit, Quantity, and Profit Margin
- Regional Sales Analysis
- Discount Impact on Profitability
- Category-wise Profit Analysis
- Interactive Filters and Dashboard Visualizations

## Key Insights
- Higher discounts negatively impacted profitability
- Technology category generated the highest profit
- West region recorded the highest sales performance
